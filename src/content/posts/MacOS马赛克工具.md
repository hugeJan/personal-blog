mac图片预览APP没有提供方便的打马方式，因此我做了这个[MosaicPhotos](https://github.com/hugeJan/MosaicPhotos)工具，能够比较方便的在截图后或者对现有文件进行快速打马赛克。

## 提供了三种使用方式

| 入口                 | 用法                                                         |
| -------------------- | ------------------------------------------------------------ |
| 完整编辑器           | 从 Finder、预览或「打开方式 → MosaicPhotos」打开图片，进行完整编辑。 |
| 系统分享扩展         | 从分享菜单快速处理图片、保存副本或拷贝结果。                 |
| 「照片」App 编辑扩展 | 直接编辑照片库中的静态图片，也可以创建新副本。               |
